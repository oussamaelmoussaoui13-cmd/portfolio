# Images des projets

Déposez ici les captures d'écran de vos projets (format `.webp` ou `.png`
recommandé, ratio 16/9, environ 1280×720).

Puis référencez-les dans `js/data/projects-data.js` :

```js
image: "assets/images/projects/mon-projet.webp",
gallery: ["assets/images/projects/mon-projet-2.webp"],
```
